# TASK: Generate an Idempotent Bash Provisioning Script for Shtiya OS Desktop

You are an expert DevOps engineer and Linux systems architect. Write a single, robust, and idempotent bash script (`provision_shtiya_desktop.sh`) that applies aggressive structural hardening to a headless Debian `sid` N2 VM running GNOME and Chrome Remote Desktop. The script must include `set -e` and clear `echo` status indicators.

Translate these 5 architectural requirements into bash automation:

1. Annihilate GNOME Tracker Subsystem (Run as Standard User)
- Terminate active tracker3 daemons, hard reset the filesystem, and remove `~/.cache/tracker` and `~/.local/share/tracker`.
- Execute `systemctl --user mask` on: `tracker-store.service`, `tracker-miner-fs.service`, `tracker-miner-fs-3.service`, `tracker-extract.service`, `tracker-extract-3.service`, `tracker-miner-apps.service`, `tracker-writeback.service`, and `tracker-writeback-3.service`.
- Copy `/etc/xdg/autostart/tracker-*.desktop` to `~/.config/autostart/` and append `Hidden=true` to each file.

2. Framebuffer Sovereignty (Disable GDM & Wayland) (Run as Root)
- Disable and stop `gdm3.service` via `systemctl`.
- Use `sed` to uncomment and enforce `WaylandEnable=false` in both `/etc/gdm3/custom.conf` and `/etc/gdm3/daemon.conf`.
- Create `~/.chrome-remote-desktop-session` for the user, inject `exec /etc/X11/Xsession /usr/bin/gnome-session`, and make it executable.

3. Patch Chrome Remote Desktop Python Daemon (Run as Root)
- Stop the active CRD daemon. Backup `/opt/google/chrome-remote-desktop/chrome-remote-desktop` to a `.orig` file.
- Using sed:
  - Change `FIRST_X_DISPLAY_NUMBER = 20` to `FIRST_X_DISPLAY_NUMBER = 0`.
  - Change `DEFAULT_SIZES = "1600x1200,3840x2560"` to `DEFAULT_SIZES = "1920x1080,2560x1440,3840x2160"`.
  - Change `DEFAULT_SIZE_NO_RANDR = "1600x1200"` to `DEFAULT_SIZE_NO_RANDR = "1920x1080"`.
  - Comment out `while os.path.exists(X_LOCK_FILE_TEMPLATE % display):` and `display += 1`.

4. VirtualGL Injection (Run as Root)
- Add VirtualGL GPG key from `packagecloud.io/dcommander/virtualgl/gpgkey` to `/etc/apt/trusted.gpg.d/VirtualGL.gpg`.
- Add repository `deb https://packagecloud.io/dcommander/virtualgl/any/ any main`, update apt, and install `virtualgl` and `virtualgl32`.
- Run `/opt/VirtualGL/bin/vglserver_config -config +s +f -t`.
- Add the current user (`$USER`) to the `vglusers` group.

5. Persistent Identity Binding (Run as Mixed)
- Add the current user to the `chrome-remote-desktop` group.
- Enable and start the service specifically for the user via `sudo systemctl enable chrome-remote-desktop@$USER.service` and `sudo systemctl start chrome-remote-desktop@$USER.service`.
